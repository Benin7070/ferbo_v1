# Ferbo v1

A project to build a small LLM model that actually works, designed to understand the inner workings of Large Language Models.

## Project Overview

This repository contains an exploration into building and understanding how LLMs function under the hood. Through hands-on implementation and experimentation, we aim to demystify the mechanisms that power modern language models.

## Purpose

- 🎯 Build a functional small-scale LLM
- 🔍 Deep dive into LLM architecture and mechanics
- 📚 Learn and document the learning process
- 💡 Provide insights into model behavior and training
