# Ferbo v1

A project to build a small LLM model that actually works, designed to understand the inner workings of Large Language Models.

## Project Overview

This repository contains an exploration into building and understanding how LLMs function under the hood. Through hands-on implementation and experimentation, we aim to demystify the mechanisms that power modern language models.

## Purpose

- 🎯 Build a functional small-scale LLM
- 🔍 Deep dive into LLM architecture and mechanics
- 📚 Learn and document the learning process
- 💡 Provide insights into model behavior and training

## Architecture & Design

This project uses **Llama 2** as the reference architecture. Rather than blindly implementing a transformer from first principles, we leverage Llama 2 as a grounded base to understand proven design patterns and architectural decisions made by industry experts. This approach allows us to:

- Learn from battle-tested architectural choices
- Understand the rationale behind specific design decisions
- Build on proven foundations rather than experimenting without guidance
- Accelerate learning by studying a real-world LLM implementation

By keeping Llama 2 as our reference point, we ensure our implementation is grounded in practical, production-proven methodology.
